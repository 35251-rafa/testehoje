# Regras do projeto
- Site de portfólio pessoal em HTML, CSS e JavaScript puro (sem frameworks).
- Antes de criar ou alterar qualquer coisa, leia referencias.md, identidade.md e funcionalidades.md.
- Mantenha o código organizado: um arquivo CSS, um JS e o HTML com seções bem nomeadas.
- Estilo Tech / Cyber-Moderno: visual Dark marcante, com elementos modernos de interface, cantos levemente arredondados, bordas com iluminação sutil e tipografia forte.
- O site deve ser sempre responsivo (funcionar perfeitamente no celular e no computador).
- REGRA CRÍTICA: Não utilize nenhum tipo de scroll travado (scrolljacking). A rolagem da página DEVE ser 100% natural e fluida do próprio navegador.
- Depois de cada mudança, explique em 2 linhas o que foi feito.
